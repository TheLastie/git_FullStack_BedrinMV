# Python Console Exercise

**Русский** | [English](README.en.md)

Небольшая учебная программа на Python, которая выводит заранее заданный текст. В репозитории один исходный файл — `Main_BedrinMV.py`.

## Что находится в репозитории

- Однофайловый скрипт с точкой входа `main()`.
- Внешние зависимости и конфигурация сборки не требуются.

## Запуск и настройка

Нужен Python 3. Запустите `python Main_BedrinMV.py` из корня репозитория.

## Примечания

Это небольшой учебный пример, а не полнофункциональное full-stack приложение.
